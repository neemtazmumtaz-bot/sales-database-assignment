# Sales Database SQL Assignment

## Description

This assignment contains SQL queries performed on the `sales` database using MySQL.

## Database

Database used:

```sql
USE sales;
```

## Questions Completed

### Question 1: Retrieve Payment Information

Retrieved:

* checkNumber
* paymentDate
* amount

### Question 2: Find Orders in Process

Retrieved orders with the status `In Process` and sorted them by `orderDate` in descending order.

### Question 3: Find Sales Representatives

Retrieved employees whose job title is `Sales Rep` and sorted them by `employeeNumber` in descending order.

### Question 4: Retrieve Office Information

Retrieved all columns and records from the `offices` table.

### Question 5: Retrieve the Five Cheapest Products

Retrieved `productName` and `quantityInStock`, sorted by `buyPrice` in ascending order, with only 5 records displayed.
